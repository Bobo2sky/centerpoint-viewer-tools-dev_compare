# x方向距离分段评估说明

## 功能概述

评估程序现在支持按 x 方向距离分段评估目标检测性能，可以分析不同距离范围内的检测效果。

## x 方向分段设置

当前配置的距离分段为：
- `[-20, 0)` 米：后方区域
- `[0, 20)` 米：近距离前方
- `[20, 40)` 米：中距离前方
- `[40, 60)` 米：远距离前方  
- `[60, 80)` 米：超远距离前方

## 评估结果示例

### 按距离分段的总体指标

| x范围(米)     | mAP   | NDS   | mATE  | GT数  | Pred数 |
|--------------|-------|-------|-------|-------|--------|
| [-20, 0)     | 0.4470| 0.6916| 0.1643| 4830  | 4542   |
| [0, 20)      | 0.5517| 0.7470| 0.1633| 5111  | 4808   |
| [20, 40)     | 0.4890| 0.7116| 0.1851| 4173  | 3870   |
| [40, 60)     | 0.3955| 0.6555| 0.2379| 2798  | 2457   |
| [60, 80)     | 0.2724| 0.5853| 0.2788| 1709  | 1342   |

### 关键发现

1. **最佳性能区域**: [0, 20) 米
   - 最高的 mAP (0.5517) 和 NDS (0.7470)
   - 最低的定位误差 mATE (0.1633米)

2. **性能随距离衰减**:
   - mAP 从近距离的 0.5517 下降到超远距离的 0.2724
   - NDS 从 0.7470 下降到 0.5853
   - mATE 从 0.1633米 增加到 0.2788米

3. **目标分布**:
   - 近距离 [0, 20) 米有最多的目标 (5111个GT)
   - 超远距离 [60, 80) 米目标最少 (1709个GT)

## 修改 x 范围分段

要修改距离分段，编辑 `eval.py` 中的 `main()` 函数：

```python
# x方向距离分段
x_ranges = [
    (-20, 0),   # 后方
    (0, 20),    # 近距离
    (20, 40),   # 中距离
    (40, 60),   # 远距离
    (60, 80)    # 超远距离
]
```

可以根据需要添加或修改范围，例如：
```python
x_ranges = [
    (0, 10),
    (10, 30),
    (30, 50),
    (50, 100)
]
```

## 使用方法

运行评估程序：
```bash
python eval.py
```

程序会自动：
1. 评估每个 x 范围内的目标
2. 计算各范围的 mAP、NDS、mATE 等指标
3. 打印详细的分段评估结果
4. 保存完整结果到 `output/evaluation_results.json`

## 输出文件

- `output/evaluation_results.json`: 完整的评估结果，包括全局指标和分段指标
- 包含每个类别在每个距离范围内的详细指标
- 包含格式化的文本输出便于阅读

## 注意事项

1. x 坐标为目标框中心点的 x 坐标
2. 范围为左闭右开区间 `[x_min, x_max)`
3. 如果某个范围内没有 GT 目标，该范围会被跳过
4. 分段评估不影响全局指标的计算
